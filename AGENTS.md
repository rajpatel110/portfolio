# Agent conventions
- Work in this repository root. Use npm.cmd in PowerShell.
- Keep profile content typed in data/profile.ts. Do not invent experience or projects.
- Current scope includes navigation, hero, educational context, Selected Work, About, Skills, Contact, and the footer. Keep project evidence in docs/PROJECT_SOURCES.md and typed content in data/projects.ts.
- Preserve readable server-rendered content and reduced-motion behavior. Scope GSAP with useGSAP and clean up media contexts.
- Keep originals in ignored references/; only web-ready assets belong in public/.
- Run npm.cmd run lint, npm.cmd run typecheck, and npm.cmd run build after code changes.
- Do not commit, push, or deploy without user authorization.
